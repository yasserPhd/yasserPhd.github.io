# Yasser Oussalah — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No installation or build step required.

## Preview
Open index.html in a browser.

## GitHub Pages
1. Create a repository and upload index.html to its root.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. GitHub will show the published URL.

## Before sharing
Add your verified LinkedIn, GitHub, and contact links. Add a real screenshot or short video of The Garage in place of its abstract illustration. The page currently avoids placeholder URLs, unavailable CV downloads, and deployment claims.

For a personal homepage, name the repository YOUR_USERNAME.github.io. Otherwise this page also works under a repository subpath.
